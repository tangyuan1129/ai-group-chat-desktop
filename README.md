![桌面应用界面截图描述：顶部是四个角色徽章（经理/策划/工程师/评审），中间是聊天区，底部是任务输入框]

## ✨ 这是什么

一个**中文桌面程序**（Windows）。一次对话里同时有 4 个 AI，每个 AI 用**不同的模型**，所以观点天然不同、有来有回：

| 角色 | 默认模型 | 干什么 |
|---|---|---|
| **经理** | 云端 GLM | 拆解问题、裁决分歧、分配任务 |
| **策划** | 本地 Qwen | 提点子、出方案、敢反驳 |
| **工程师** | 云端 GLM | 评估可行性、动手干活 |
| **评审** | 本地 Qwen | 挑毛病、总结、验收（APPROVE） |

你只需要输入一句任务，四个 AI 就会自己开讨论会，直到给出结论。

## 🛠️ 四类工具（AI 会真动手）

| 工具 | 用途 |
|---|---|
| 🌐 **联网搜索** | 实时查资料（Bing，免 Key） |
| 📁 **文件读写** | 把方案写成文件，存到 `output` 文件夹 |
| 🐙 **GitHub 操作** | 查仓库、搜项目、看 Issue |
| ⚡ **执行命令** | 只读查系统信息（危险操作已拦截） |

每个角色使用哪些工具可以在代码里调整（见 `desktop_app.py` 的 `ROLE_TOOLS`）。

## 🎨 自己配置 AI

点窗口右上角 **「⚙ 配置模型」**，每个角色都能单独选：

- **智谱 GLM**（云端）：glm-4.5 ~ glm-5.3 全系
- **本地 Ollama**：自动检测你电脑上的开源模型
- **自定义 API**：任何 OpenAI 兼容接口（DeepSeek、Kimi 等）

每个角色的人设提示词也可以自己改。配置存 `team_settings.json`，重启不丢。

## 📜 历史记录

每次讨论结束自动存档。点 **「📜 历史记录」** 可回看任何一次完整对话（含工具过程）。记录存在 `history` 文件夹。

## 🚀 安装运行（Windows）

### 前提

1. **Python 3.10+** 和 **Ollama**（可选，跑本地模型用，[官网下载](https://ollama.com)）
2. 拉一个本地模型（可选）：`ollama pull qwen2.5:7b`
3. **智谱 API Key**：[申请地址](https://open.bigmodel.cn)（有免费额度）

### 步骤

```bat
:: 1. 解压本程序到任意目录
:: 2. 安装依赖
pip install -r requirements.txt

:: 3. 配置密钥：把 .env.example 复制一份改名为 .env，填入你的智谱 Key
:: 4. 双击运行
start_desktop.bat
```

程序启动后，在底部输入任务，回车即可看到四个 AI 开始讨论。

### 效果示例

输入：
> 搜索 500 元以内适合新手的机械键盘推荐，四人讨论后把最终清单写入文件

四个 AI 会联网搜索 → 讨论分工 → 工程师把清单写成文件 → 评审验收 → `output` 文件夹里多出一份真实可用的清单。

## ⚠️ 说明

- 工具只能读写程序目录下的 `output` 文件夹（防越权）；删除/关机等危险命令已被拦截
- 智谱免费接口偶尔限流（429），程序会自动等待重试，无需干预
- 本项目是个人开发的小工具，用于学习和演示多 Agent 协作

## 📁 文件结构

```
ai-group-chat/
├── desktop_app.py      # 主程序（界面 + 团队调度）
├── tools.py            # AI 的"手臂"：搜索 / 文件 / GitHub / 命令
├── glm_client.py       # 智谱 GLM 客户端（含限流自动重试）
├── start_desktop.bat   # 双击启动器（无黑窗）
├── requirements.txt    # Python 依赖
├── .env.example        # 密钥模板（复制为 .env 并填写）
├── output/             # AI 写出的文件都会放在这里
└── history/            # 历史聊天记录（自动生成）
```
